# DataCamp Power BI catalog: topic-level syllabus

Source: DataCamp course pages, read 2026-10-27. Topic keywords only, no copied text. Level "Basic" is DataCamp's word for beginner.
Catalog check: the DataCamp Power BI category page lists exactly the 30 Power BI courses below, plus Introduction to Microsoft Fabric. Searches found no other DataCamp Power BI, DAX, Fabric or Copilot-in-Power-BI course. The Microsoft Copilot courses (Intro, Working with, in PowerPoint, in Excel) do not cover Power BI.
Tracks: Power BI Fundamentals (skill track); Data Analyst in Power BI (career track, courses 1-17 in this order, plus the "Power BI for Data Analysts" assessment).

## Introduction to Power BI (Basic) https://www.datacamp.com/courses/introduction-to-power-bi
- Getting Started: Power BI Desktop, first report page, report brief, page layout, eye guidance / reader focus, key insights
- Preparing Data: data connections, data shaping, data cleaning, no-code transformation, data model
- Visualizing Effectively: visual insights, interactive reports, data exploration, user controls (slicers/filters)

## Introduction to DAX in Power BI (Basic) https://www.datacamp.com/courses/introduction-to-dax-in-power-bi
- Getting Started with DAX: DAX basics, calculated columns, measures, table expansion, summarization
- Context in DAX Formulas: row vs filter context, iterator functions, CALCULATE, filtering, variables (VAR)
- Working with Dates: date/time intelligence functions, quick measures, more complex DAX

## Data Visualization in Power BI (Basic) https://www.datacamp.com/courses/data-visualization-in-power-bi

- Less is More: decluttering, simplification, focus on key insights

## Data Preparation in Power BI (Basic) https://www.datacamp.com/courses/data-preparation-in-power-bi

## Data Modeling in Power BI (Basic) https://www.datacamp.com/courses/data-modeling-in-power-bi
