# Lezzet Kurye · Power BI Desktop referans raporu

[Power BI proje paketini indir](https://ysfdurak.github.io/kesit-powerbi/veri/lezzet-kurye-desktop-referans.zip).

1–14 Ekim 2024 tarihli 903 sentetik siparişle teslimat SLA’sı ve ilçe performansı. Pakette iki rapor sayfası, üç tablo, yedi DAX ölçüsü, beş kontrol senaryosu ve kurulum adımları var.

ZIP’in tamamını çıkarıp Power BI Desktop’ta `Lezzet-Kurye.pbip` dosyasını aç. Yenilemeden sonra `DOGRULAMA.md` tablosunu ve `Kontrol-Sorgusu.dax` sorgusunu kullan.

Durum: JSON şema ve veri mutabakatı kontrolleri geçti. Windows Power BI Desktop açılış, yenileme ve görsel inceleme kaydı bekliyor.
